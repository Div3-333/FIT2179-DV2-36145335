### PART 3: The Brutal & Paranoid Engineer Review

Looking at this plan, here are the failure vectors I see that could crash your assignment right before submission. You need to watch your agents closely for these:

1. **The Cross-Origin Resource Sharing (CORS) Trap on Maps:**
   * *The Risk:* In `chart1.json`, we are pulling a GeoJSON map from a raw GitHub URL. Sometimes, browsers block this due to CORS policies if you are testing locally (opening the HTML file straight from your desktop).
   * *The Fix:* If the map doesn't render locally, don't panic. You will need to either run a local Python server (`python -m http.server`) or download that GeoJSON file directly into your `data` folder and change the URL in the Vega-Lite code to `"url": "data/suburb-10-vic.geojson"`.

2. **Temporal Parsing Nightmares:**
   * *The Risk:* CSV dates are notoriously dirty. The agent might assume your `YearMonth` column in `soi_monthly.csv` (e.g., `201501`) is a standard date. Vega-Lite will fail silently and plot nothing.
   * *The Fix:* Ensure the agents use Vega-Lite's specific time parsing directives in the data block: `"format": {"parse": {"YearMonth": "date:'%Y%m'"}}`. 

3. **The "Wide" vs. "Long" Data Trap (Charts 5 & 8):**
   * *The Risk:* Your rainfall data (`caulfield_rain.csv`) and water usage data (`total-use-by-resource.csv`) are currently in "wide" format (e.g., columns for Jan, Feb, Mar, or columns for Surface, Groundwater). Vega-Lite struggles to plot multiple lines from wide formats natively without complex `fold` transforms.
   * *The Fix:* Ensure the agents write a `"transform": [{"fold": [...]}]` block in the JSON, or proactively convert those CSVs into a "long" format (e.g., Columns: `Year`, `Month`, `Rainfall_mm`) before feeding them to the agent.

4. **Responsive Width Failures:**
   * *The Risk:* If the agent hardcodes `"width": 800` into the JSON, it will break the mobile view of your beautiful CSS Bento/Scrollytelling layout. 
   * *The Fix:* The agent MUST use `"width": "container"` in the root of every JSON file so the chart flexes to fit the HTML `div` we built. 

Keep an eye on the agents. They are brilliant typists but terrible architects. Force them to test locally frequently!
